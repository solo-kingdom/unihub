## MODIFIED Requirements

### Requirement: 响应式布局
系统 SHALL 使用自定义 div + flex 布局构建暖色卡片式管理界面，侧边栏和内容区均为白底圆角卡片。页面整体高度 SHALL 精确匹配浏览器视口高度（`100vh`），无全页滚动条。内容溢出时，仅内容区域（`.unihub-content`）内部滚动，侧边栏（`.unihub-sidebar`）保持固定不滚动（`overflow: hidden`）。适配主流浏览器。

#### Scenario: 界面适配
- **WHEN** 在不同分辨率的浏览器中访问
- **THEN** 页面整体精确占满视口高度，无全页垂直滚动条。侧边栏可在展开/图标/隐藏三态间切换，内容区自动填充剩余空间并仅在自身溢出时内部滚动，界面布局合理，核心功能可正常使用

#### Scenario: 内容溢出时仅内容区滚动
- **WHEN** 右侧内容区内容高度超出可用空间
- **THEN** 内容区内部出现垂直滚动条，侧边栏保持固定不动，页面整体无滚动条
