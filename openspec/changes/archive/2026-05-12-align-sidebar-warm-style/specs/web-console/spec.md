## MODIFIED Requirements

### Requirement: SPA 路由框架
系统 SHALL 使用 React Router 构建 SPA 应用，采用 `<Outlet />` 嵌套路由模式。布局使用自定义 div + flex 构建，全局背景为暖色渐变。侧边栏为暖色白底卡片式设计，支持三态交互（展开/图标/隐藏）。菜单项使用 `<Link>` 组件实现客户端路由跳转，当前选中菜单项通过 `useLocation()` 动态同步。

#### Scenario: 页面路由
- **WHEN** 用户访问应用
- **THEN** 全局显示暖色渐变背景，左侧显示白底暖色侧边栏导航菜单（数据源管理、数据查询），侧边栏为圆角卡片容器，右侧内容区为白底圆角卡片，通过 `<Outlet />` 渲染对应页面

#### Scenario: 侧边栏展开态
- **WHEN** 侧边栏处于展开模式
- **THEN** 侧边栏宽度 200px，显示完整 Logo 文字和菜单项文字，底部显示两个控制按钮（折叠为图标模式、隐藏侧边栏）

#### Scenario: 侧边栏图标态
- **WHEN** 侧边栏处于图标模式
- **THEN** 侧边栏宽度 60px，仅显示 Logo 首字母和菜单图标，底部显示两个控制按钮（展开为完整模式、隐藏侧边栏）

#### Scenario: 侧边栏隐藏态
- **WHEN** 侧边栏处于隐藏模式
- **THEN** 侧边栏不可见，内容区占满全宽，左下角显示 FAB 按钮可恢复展开，鼠标移入左边缘 8px 触发区时显示浮层侧边栏

#### Scenario: 浮层侧边栏
- **WHEN** 侧边栏隐藏时鼠标移入左边缘触发区
- **THEN** 以浮层形式显示完整侧边栏（200px 宽），鼠标移出后浮层消失

### Requirement: 响应式布局
系统 SHALL 使用自定义 div + flex 布局构建暖色卡片式管理界面，侧边栏和内容区均为白底圆角卡片，适配主流浏览器。

#### Scenario: 界面适配
- **WHEN** 在不同分辨率的浏览器中访问
- **THEN** 侧边栏可在展开/图标/隐藏三态间切换，内容区自动填充剩余空间，界面布局合理，核心功能可正常使用
