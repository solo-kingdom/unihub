## MODIFIED Requirements

### Requirement: 数据源管理页面
系统 SHALL 提供数据源管理页面，支持数据源列表展示（含类型和实现过滤）、新增（级联选择：类型 → 实现 → 配置表单）、编辑和删除操作。编辑模式下打开表单时 SHALL 正确回显所有已保存的配置字段值（包括动态渲染的连接参数如地址、密码、端口等）。

#### Scenario: 数据源列表展示
- **WHEN** 进入数据源管理页面
- **THEN** 以表格形式展示所有已注册数据源，列包含名称、类型名称、实现名称、创建时间，列表顶部提供类型和实现的下拉过滤框，支持分页

#### Scenario: 新增数据源（级联选择）
- **WHEN** 点击"新增数据源"按钮
- **THEN** 弹出表单 Modal，依次选择：名称输入 → 类型下拉框（如 KV 存储、配置中心）→ 实现下拉框（根据所选类型动态过滤可选实现）→ 连接配置表单（根据所选实现动态渲染字段），提交后刷新列表

#### Scenario: 编辑数据源
- **WHEN** 点击某个数据源的"编辑"操作
- **THEN** 弹出预填充当前配置的编辑表单（类型和实现字段不可修改），所有配置字段 SHALL 显示当前已保存的值，提交后更新数据源

#### Scenario: 编辑表单字段回显机制
- **WHEN** 编辑弹窗打开，Form 使用默认 `preserve={true}`
- **THEN** 名称、类型、实现字段在 `handleOpenEdit` 中通过 `form.setFieldsValue` 同步设置（这些字段始终在 DOM 中），动态 config 字段在 `useEffect` 中设置（依赖 `modalOpen`、`editingDs`、`currentImplMeta`，确保 Form.Item 已挂载）
- **AND** config 字段在弹窗打开后正确显示已保存值

#### Scenario: 删除数据源
- **WHEN** 点击某个数据源的"删除"操作
- **THEN** 弹出确认对话框，确认后删除数据源并刷新列表

#### Scenario: 连接测试
- **WHEN** 在新增/编辑表单中点击"测试连接"按钮
- **THEN** 调用连接测试 API，显示测试结果（成功/失败及原因）
