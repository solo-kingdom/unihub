## ADDED Requirements

### Requirement: SPA 路由框架
系统 SHALL 使用 React Router 构建 SPA 应用，采用 `<Outlet />` 嵌套路由模式，侧边栏为暗色可折叠设计。菜单项使用 `<Link>` 组件实现客户端路由跳转，当前选中菜单项通过 `useLocation()` 动态同步。

#### Scenario: 页面路由
- **WHEN** 用户访问应用
- **THEN** 左侧显示暗色（`#1a1a2e`）可折叠导航菜单（数据源管理、数据查询），右侧内容区通过 `<Outlet />` 渲染对应页面，无独立全局 Header

### Requirement: 数据源管理页面
系统 SHALL 提供数据源管理页面，支持数据源列表展示（含类型和实现过滤）、新增（级联选择：类型 → 实现 → 配置表单）、编辑和删除操作。

#### Scenario: 数据源列表展示
- **WHEN** 进入数据源管理页面
- **THEN** 以表格形式展示所有已注册数据源，列包含名称、类型名称、实现名称、创建时间，列表顶部提供类型和实现的下拉过滤框，支持分页

#### Scenario: 新增数据源（级联选择）
- **WHEN** 点击"新增数据源"按钮
- **THEN** 弹出表单 Modal，依次选择：名称输入 → 类型下拉框（如 KV 存储、配置中心）→ 实现下拉框（根据所选类型动态过滤可选实现）→ 连接配置表单（根据所选实现动态渲染字段），提交后刷新列表

#### Scenario: 编辑数据源
- **WHEN** 点击某个数据源的"编辑"操作
- **THEN** 弹出预填充当前配置的编辑表单（类型和实现字段不可修改），提交后更新数据源

#### Scenario: 删除数据源
- **WHEN** 点击某个数据源的"删除"操作
- **THEN** 弹出确认对话框，确认后删除数据源并刷新列表

#### Scenario: 连接测试
- **WHEN** 在新增/编辑表单中点击"测试连接"按钮
- **THEN** 调用连接测试 API，显示测试结果（成功/失败及原因）

### Requirement: 数据查询页面
系统 SHALL 提供数据查询页面，支持选择数据源后浏览和查询数据。

#### Scenario: 选择数据源
- **WHEN** 进入数据查询页面
- **THEN** 页面顶部提供数据源选择下拉框，列出所有已注册数据源

#### Scenario: 浏览键列表
- **WHEN** 选择某个 KV 类型数据源
- **THEN** 左侧面板显示该数据源的所有键名列表

#### Scenario: 查看键值详情
- **WHEN** 点击键列表中的某个键
- **THEN** 右侧面板显示该键对应的值内容（JSON 格式化显示）

#### Scenario: 新增键值
- **WHEN** 在数据查询页面点击"新增"按钮
- **THEN** 弹出键值输入表单，提交后写入数据并刷新键列表

#### Scenario: 编辑键值
- **WHEN** 在值详情面板点击"编辑"
- **THEN** 切换为可编辑模式，修改后提交更新

#### Scenario: 删除键值
- **WHEN** 点击某个键的"删除"操作
- **THEN** 弹出确认对话框，确认后删除并刷新列表

### Requirement: 响应式布局
系统 SHALL 使用 Ant Design 的 Layout 组件构建暗色侧边栏风格的响应式管理界面，适配主流浏览器。

#### Scenario: 界面适配
- **WHEN** 在不同分辨率的浏览器中访问
- **THEN** 侧边栏可折叠，内容区自动填充剩余空间，界面布局合理，核心功能可正常使用
