## Purpose

定义 Web 控制台前端界面的需求规范，包括 SPA 路由框架、侧边栏交互、数据源管理页面、数据查询页面以及响应式布局。
## Requirements
### Requirement: SPA 路由框架
系统 SHALL 使用 React Router 构建 SPA 应用，采用 `<Outlet />` 嵌套路由模式。布局使用自定义 div + flex 构建，全局背景为暖色渐变。侧边栏为暖色白底卡片式设计，支持三态交互（展开/图标/隐藏）。菜单项使用 `<Link>` 组件实现客户端路由跳转，当前选中菜单项通过 `useLocation()` 动态同步。

#### Scenario: 页面路由
- **WHEN** 用户访问应用
- **THEN** 全局显示暖色渐变背景，左侧显示白底暖色侧边栏导航菜单（数据源管理、数据查询），侧边栏为圆角卡片容器，右侧内容区为白底圆角卡片，通过 `<Outlet />` 渲染对应页面

#### Scenario: 侧边栏展开态
- **WHEN** 侧边栏处于展开模式
- **THEN** 侧边栏宽度 200px，显示完整 Logo 文字和菜单项文字，底部显示两个控制按钮（折叠为图标模式、隐藏侧边栏）

#### Scenario: 侧边栏图标态
- **WHEN** 侧边栏处于图标模式
- **THEN** 侧边栏宽度 60px，仅显示 Logo 首字母和菜单图标，底部显示两个控制按钮（展开为完整模式、隐藏侧边栏）

#### Scenario: 侧边栏隐藏态
- **WHEN** 侧边栏处于隐藏模式
- **THEN** 侧边栏不可见，内容区占满全宽，左下角显示 FAB 按钮可恢复展开，鼠标移入左边缘 8px 触发区时显示浮层侧边栏

#### Scenario: 浮层侧边栏
- **WHEN** 侧边栏隐藏时鼠标移入左边缘触发区
- **THEN** 以浮层形式显示完整侧边栏（200px 宽），鼠标移出后浮层消失

### Requirement: 数据源管理页面
系统 SHALL 提供数据源管理页面，支持数据源列表展示（含类型和实现过滤）、新增（级联选择：类型 → 实现 → 配置表单）、编辑和删除操作。编辑模式下打开表单时 SHALL 正确回显所有已保存的配置字段值（包括动态渲染的连接参数如地址、密码、端口等）。

#### Scenario: 数据源列表展示
- **WHEN** 进入数据源管理页面
- **THEN** 以表格形式展示所有已注册数据源，列包含名称、类型名称、实现名称、创建时间，列表顶部提供类型和实现的下拉过滤框，支持分页

#### Scenario: 新增数据源（级联选择）
- **WHEN** 点击"新增数据源"按钮
- **THEN** 弹出表单 Modal，依次选择：名称输入 → 类型下拉框（如 KV 存储、配置中心）→ 实现下拉框（根据所选类型动态过滤可选实现）→ 连接配置表单（根据所选实现动态渲染字段），提交后刷新列表

#### Scenario: 编辑数据源
- **WHEN** 点击某个数据源的"编辑"操作
- **THEN** 弹出预填充当前配置的编辑表单（类型和实现字段不可修改），所有配置字段 SHALL 显示当前已保存的值，提交后更新数据源

#### Scenario: 删除数据源
- **WHEN** 点击某个数据源的"删除"操作
- **THEN** 弹出确认对话框，确认后删除数据源并刷新列表

#### Scenario: 连接测试
- **WHEN** 在新增/编辑表单中点击"测试连接"按钮
- **THEN** 调用连接测试 API，显示测试结果（成功/失败及原因）

### Requirement: 数据查询页面
系统 SHALL 提供数据查询页面，支持选择数据源后浏览、搜索、随机获取和查询数据。

#### Scenario: 选择数据源
- **WHEN** 进入数据查询页面
- **THEN** 页面顶部提供数据源选择下拉框，列出所有已注册数据源

#### Scenario: 浏览键列表
- **WHEN** 选择某个 KV 类型数据源
- **THEN** 左侧面板显示该数据源的所有键名列表，面板头部包含 key 搜索输入框和「随机」按钮

#### Scenario: 搜索键列表
- **WHEN** 在 key 搜索输入框中输入搜索模式
- **THEN** key 列表实时过滤为匹配该模式的 key，面板标题更新为匹配后的数量

#### Scenario: 随机获取键
- **WHEN** 点击「随机」按钮
- **THEN** 系统从数据源中随机选取一个 key，自动在列表中选中并加载其值

#### Scenario: 查看键值详情
- **WHEN** 点击键列表中的某个键
- **THEN** 右侧面板显示该键对应的值内容（JSON 格式化显示）

#### Scenario: 新增键值
- **WHEN** 在数据查询页面点击"新增"按钮
- **THEN** 弹出键值输入表单，提交后写入数据并刷新键列表。若输入的 key 名已存在则提示用户

#### Scenario: 编辑键值
- **WHEN** 在值详情面板点击"编辑"
- **THEN** 切换为可编辑模式，修改后提交更新

#### Scenario: 删除键值
- **WHEN** 点击某个键的"删除"操作
- **THEN** 弹出确认对话框，确认后删除并刷新列表

### Requirement: Key 存在性检查
系统 SHALL 在新增键值表单中检测重复 key 名。当用户输入 key 名称时，系统 SHALL 检查该 key 是否已存在于当前数据源中，若存在则给出提示。

#### Scenario: 输入已存在的 key 名
- **WHEN** 用户在新增键值 Modal 中输入一个已存在的 key 名称（防抖 500ms 后触发检查）
- **THEN** 在 key 输入框下方显示警告提示「该键名已存在，继续添加将覆盖原值」

#### Scenario: 输入不存在的 key 名
- **WHEN** 用户在新增键值 Modal 中输入一个不存在的 key 名称
- **THEN** 不显示任何警告提示

### Requirement: 响应式布局
系统 SHALL 使用自定义 div + flex 布局构建暖色卡片式管理界面，侧边栏和内容区均为白底圆角卡片。页面整体高度 SHALL 精确匹配浏览器视口高度（`100vh`），无全页滚动条。内容溢出时，仅内容区域（`.unihub-content`）内部滚动，侧边栏（`.unihub-sidebar`）保持固定不滚动（`overflow: hidden`）。适配主流浏览器。

#### Scenario: 界面适配
- **WHEN** 在不同分辨率的浏览器中访问
- **THEN** 页面整体精确占满视口高度，无全页垂直滚动条。侧边栏可在展开/图标/隐藏三态间切换，内容区自动填充剩余空间并仅在自身溢出时内部滚动，界面布局合理，核心功能可正常使用

#### Scenario: 内容溢出时仅内容区滚动
- **WHEN** 右侧内容区内容高度超出可用空间
- **THEN** 内容区内部出现垂直滚动条，侧边栏保持固定不动，页面整体无滚动条

### Requirement: Aerospike 连接失败重试
系统 SHALL 在数据查询页面中，当选中 Aerospike 数据源后连接测试失败时，在「连接失败」状态 Tag 旁提供「重试」按钮，用户点击后重新发起连接测试并更新状态。

#### Scenario: 显示重试按钮
- **WHEN** 选中 Aerospike 数据源且连接测试返回失败状态
- **THEN** 「连接失败」红色 Tag 右侧显示「🔄 重试」按钮

#### Scenario: 点击重试成功
- **WHEN** 用户点击「重试」按钮，且本次连接测试成功
- **THEN** 连接状态 Tag 更新为绿色「已连接」，重试按钮消失

#### Scenario: 点击重试仍失败
- **WHEN** 用户点击「重试」按钮，且连接测试仍然失败
- **THEN** 连接状态 Tag 保持红色「连接失败」，重试按钮继续可见待下次重试

#### Scenario: 连接成功时不显示重试按钮
- **WHEN** 选中 Aerospike 数据源且连接测试成功
- **THEN** 仅显示绿色「已连接」Tag，不显示重试按钮

### Requirement: 新增键值 Modal 展示 namespace 和 set 上下文
系统 SHALL 在数据查询页面的「新增键值」Modal 中，对 Aerospike 数据源在表单顶部显示当前写入目标 namespace 和 set 信息。

#### Scenario: Aerospike 数据源新增时显示 namespace 和 set
- **WHEN** 在数据查询页选中 Aerospike 数据源（namespace="test,prod"，set="users"）并打开「新增键值」Modal
- **THEN** Modal 表单顶部显示一行上下文指示：namespace 显示当前 `activeNamespace` 值（如 `test`），set 显示配置的 set 值（如 `users`，未配置时显示「默认」）

#### Scenario: 非 Aerospike 数据源不显示上下文
- **WHEN** 在数据查询页选中 Redis 或 BoltDB 数据源并打开「新增键值」Modal
- **THEN** Modal 不显示 namespace/set 上下文行，仅显示键名和值输入框

#### Scenario: 编辑模式同样适用
- **WHEN** 在数据查询页编辑已有键值，打开编辑 Modal
- **THEN** 编辑 Modal 对 Aerospike 数据源同样显示 namespace/set 上下文信息（但 set 不可编辑）
